# Visual Direction

The visual language is a senior gameplay engineering command center:

- dark cinematic base
- restrained teal and amber signals
- dense technical information hierarchy
- glass panels only where they support readability
- richer desktop ambient 3D motion
- no hidden navigation, no open-world dependency

The goal is premium production confidence, not novelty.

## Platform Direction

- Desktop/laptop/large monitor: full cinematic mode, richer environment layers, animated lighting, subtle camera response, and AAA launcher-style composition.
- Tablet: reduced cinematic mode with fewer scene modules and simpler layout density.
- Mobile: simplified mode with reduced rendering complexity and preserved readability.
